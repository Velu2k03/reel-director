# ReelDirector asset sources

Only third-party interface assets are listed here. Generated video
content (narration, scene art, voice) is produced at runtime by Meta
models and is not committed.

## Typography

Manrope variable font: https://github.com/google/fonts/tree/main/ofl/manrope
Self-hosted as `manrope-variable.ttf` under the SIL Open Font License; see `manrope-LICENSE.txt`.

## Icons

Material Symbols Outlined: https://github.com/google/material-design-icons
Self-hosted as `ui/fonts/material-symbols.woff2` (with
`ui/fonts/material-symbols.css`) under the Apache License 2.0; see
`ui/fonts/LICENSE-material-symbols.txt`.
